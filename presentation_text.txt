About VANTAGE
VANTAGE enhances decision-making by integrating risk
analysis, document verification, and policy-aware evaluation
into a single flow. By reducing manual effort and enabling
instant pre-approvals, it empowers financial institutions to
deliver faster, smarter, and more reliable lending
experiences.
VANTAGE is an AI-powered onboarding platform that
transforms the traditional loan journey into a seamless digital
experience. It combines real-time video interaction,
intelligent data extraction, and automated KYC verification
using Aadhaar, PAN, and facial analysis, ensuring fast, secure,
and compliant user onboarding.

A2A Protocol for Agent Communication
No agent operates in isolation. When one agent produces a signal that another agent needs to act on, it emits a
structured message via the A2A event bus, rather than returning to the orchestrator and back. This keeps the flow fast,
auditable and decoupled. Any agent can emit a signal; any agent can subscribe to one. The Fraud agent is the primary
subscriber, it aggregates signals from interview, KYC and Document agents to build a unified fraud score that gates the
Decision agent.
Example: Document agent detects a city mismatch → emits signal via A2A → Fraid agent updates score → Decision agent reads gate before generating offer.

Agentic Harness - Skills as Plugins
What the Harness Does 
The harness is the runtime - agents are just workers. The
harness handles routing, context, retry and audit. 
Context Injection 
Each agent gets only required context - no raw data sharing.
Dynamic Routing
LLM selects the right agent at runtime - no hardcoding.
Retry & Recovery
Auto retries with fallback - zero session drops.
Audit per Invocation
Every call is logged - immutable audit trailSkills - Guardrails for known failure points
Skills are micro-behaviours that we injected at the exact
points when an LLM is most likely to hallucinate or
violate a compliance rule.
Compliance Gate
Ensures RBI compliance before any output.
Format Guard
Validates Aadhaar & PAN before processing.
Consent Block
Blocks flow without user consent.
PII Redactor
Removes sensitive data before storage/logs.
